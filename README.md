# Hi, I'm Emmanuel

**Business Informatics student building toward a career in data engineering.**

I'm interested in how raw data becomes reliable, usable information: ingestion, transformation, modeling, and the pipelines that connect them. My repositories document that learning path, from SQL schema design to distributed processing with Apache Spark.

## Current Focus

- Building batch ETL pipelines with **PySpark** and **Delta Lake**
- Designing layered data models (staging → core → mart) in **MySQL** and **PostgreSQL**
- Containerizing development environments with **Docker**
- Exploring cloud data platforms on **AWS**
- Learning AI-assisted test automation with **Playwright**
